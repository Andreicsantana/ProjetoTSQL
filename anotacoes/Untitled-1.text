Resumo das mudanças principais
- `Carteira_Definicao` adicionada para versionar carteiras importadas; `Carteira` agora guarda quantidade teórica, peso em fração e FK para a definição.
- Procedure `usp_ImportarDataset` (arquivo `sql/carteira_tables_scripts.sql`) orquestra o fluxo staging → limpeza → carga final para cada tipo de dataset.
- A procedure normaliza números com vírgula/ponto, interpreta sufixos K/M/B, evita duplicatas via `MERGE` e atualiza `Ativos`/`Benchmarks` com os valores mais recentes.

Checklist para executar a `usp_ImportarDataset`
- Certifique-se de que o serviço SQL Server enxerga o caminho de cada CSV (permissões e montagem no container).
- Ajuste o parâmetro `@FilePath` conforme a localização real do arquivo.
- Execute os blocos abaixo apenas uma vez por arquivo ou sempre que houver atualização dos dados.
